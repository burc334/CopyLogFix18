CopyLogFix18

Fix the confirmed pasted crash caused by CopyLog 1.7.x on iOS 18.

Version 1.0.0 com.burc334.copylogfix18 MIT

Compatibility

Build Architecture Compatibility
RootHide iphoneos-arm64e Tested on iOS 18.4.1 (Dopamine 3, RootHide)
Rootless iphoneos-arm64 Expected to work on iOS 16+ rootless jailbreaks

Requires CopyLog 1.7 or 1.7.1 and iOS 16.0 or later. Where the endpoint already implements -persistentIdentifier, the tweak is a no-op.

What it fixes

CopyLog 1.7/1.7.1 injects CopyLogPasteD.dylib into the system pasted daemon. That dylib calls -persistentIdentifier on the paste's source and destination endpoints without checking that the endpoint implements it. On iOS 18.4.1 those endpoints can be DRPasteAnnouncementContinuityEndpoint, which does not implement the selector, so pasted crashes with an unrecognized selector.

CopyLogFix18 adds a non-matching -persistentIdentifier implementation to that class, but only if it does not already implement it. CopyLog's comparison then returns false and falls through to the system implementation instead of crashing.

What it does not fix

  • It is not a general iOS 18 compatibility patch for CopyLog.
  • It does not modify CopyLog's SpringBoard UI, keyboard daemon, edit menu, rich content, notifications, history, favorites, search, or scroll performance.
  • It does not replace CopyLog and contains no CopyLog code or assets.
  • Other crashes or broken features need separate evidence and separate fixes.

How it works

The tweak is filtered to the pasted executable only. At load time it checks whether DRPasteAnnouncementContinuityEndpoint implements -persistentIdentifier. If it does not, the tweak adds a method that returns a fixed non-matching NSData sentinel. The method is retried when a new dyld image loads, in case the class lives in a lazily loaded image. No CopyLog classes are swizzled and no CopyLog files are replaced.

Install

  1. Install CopyLog 1.7 or 1.7.1 first.
  2. Download the matching deb:
    • RootHide: com.burc334.copylogfix18_1.0.0_iphoneos-arm64e.deb
    • Rootless: com.burc334.copylogfix18_1.0.0_iphoneos-arm64.deb
  3. Install it with Sileo, Zebra, or Filza.
  4. Respring. The package's postinst restarts pasted.

Verification

SHA-256 checksums are published in SHA256SUMS.txt with the GitHub release. Verify the downloaded deb before installing it.
